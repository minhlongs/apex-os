## 0. Brand Foundation

### Brand Essence
ApexOS là nền tảng affiliate cashback crypto hàng đầu, kết nối người dùng với các sàn giao dịch (Binance, Bybit, OKX, KuCoin) để nhận hoàn tiền USDC qua mạng Stellar. Thương hiệu mang tinh thần **modern tech, trustworthy, premium, growth-oriented**.

### Core Values
- **Trust** — Màu xanh đậm, hình học vững chắc, typography rõ ràng
- **Growth** — Hướng lên trên, gradient sáng, dynamic elements
- **Technology** — Geometric shapes, clean lines, blockchain-inspired patterns
- **Premium** — Negative space, restrained palette, refined typography

## 2. Typography System

### Primary Typeface: Space Grotesk

| Weight | Usage | Letter Spacing |
|--------|-------|----------------|
| **Bold (700)** | Headlines, logo wordmark, section titles | -1% to 0% |
| **SemiBold (600)** | Subheadings, emphasis text | 0% |
| **Medium (500)** | Body text, labels | 0% to +1% |
| **Regular (400)** | Body copy, taglines | +2% to +3% |

### Secondary Typeface: Inter

| Weight | Usage |
|--------|-------|
| **Regular (400)** | Body text trong documents, email body |
| **Medium (500)** | UI labels, form fields |

## 3. Logo Specifications

### Logo Concept: The Ascending Apex (Primary)
Chữ "A" stylized như đỉnh núi với các đường nét blockchain nối liền từ đáy lên đỉnh. Phần trên của chữ "A" được cắt tạo khoảng trống hình tam giác hướng lên — tượng trưng cho tăng trưởng và apex.

### Lockup Variations

```
Horizontal Lockup:     Stacked Lockup:       Wordmark Only:
┌──────────────────┐   ┌──────────────┐      ┌──────────────┐
│ [Mark] APEXOS    │   │   [Mark]     │      │   APEXOS     │
│ Global Crypto    │   │   APEXOS     │      │              │

                       │ Affiliate Hub│

Icon-Only:

```

### Logo Clear Space
- Khoảng cách clear space tối thiểu = chiều cao của chữ "A" trong "APEXOS"
- Không đặt text, hình ảnh, hoặc element nào khác trong vùng clear space

### Minimum Sizes
| Format | Digital | Print |
|--------|---------|-------|
| Full lockup | 200px width | 2 inch width |
| Wordmark only | 120px width | 1.2 inch width |
| Icon-only | 24x24px | 0.5 inch |

### Color Variations

| Version | Background | Logo Color | Usage |
|---------|-----------|-----------|-------|
| **Primary** | Dark (#0A1628) | Gradient Apex Rise | Hero sections, dark mode UI |
| **Primary Light** | White (#FFFFFF) | Apex Blue (#0A1628) | Light mode UI, print materials |
| **Monochrome Dark** | Dark (#0A1628) | Stellar Cyan (#00D4FF) | Single-color applications |
| **Monochrome Light** | White (#FFFFFF) | Apex Blue (#0A1628) | Fax, embossing, engraving |
| **Reversed** | Gradient/Image | White (#FFFFFF) | Over photos, hero images |

### File Specifications

| Format | Usage | Spec |
|--------|-------|------|
| SVG | Digital, web, responsive | Vector, scalable |
| PNG (transparent) | Web, presentations | 2x size cho retina |
| PNG (solid bg) | Social media, email | Đúng kích thước platform |

## 9. Vendor Specifications

### Print Vendor Requirements
- **Color:** CMYK, US Web Coated (SWOP) v2 or ISO Coated v2
- **Bleed:** 0.125" on all sides
- **Safe zone:** 0.25" from trim
- **Fonts:** Embed all fonts or convert to outlines
- **Resolution:** 300 DPI minimum, 600 DPI for text-heavy materials
- **File format:** PDF/X-1a or PDF/X-4

### Digital Asset Specifications
- **Web:** RGB, sRGB color profile
- **Email signatures:** Inline CSS, table-based layout, max 420px width
- **QR codes:** Minimum 2cm x 2cm print size, 300 DPI, error correction Level M
